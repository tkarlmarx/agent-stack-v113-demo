# Notes

A demo repository for agent-stack V1-13: a handful of small files — README.md, HELLO.md, CONTRIBUTING.md, a `hello.sh` script, and a `package.json` whose `npm start` serves the repo statically.

It exists to exercise the agent's governed git workflow (branch, commit, push, open a PR) rather than to ship working software; there is no automated test suite yet.
