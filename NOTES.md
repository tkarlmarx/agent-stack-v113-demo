# Notes

A demo repository for agent-stack V1-13, containing only a few small files: `README.md`, this `NOTES.md`, a `hello.sh` script that prints the date and working directory, and a `package.json` whose `npm start` serves the repo over `python3 -m http.server`.

It exists to exercise the agent's governed git workflow (branch, commit, push, open a PR) rather than to ship working software; there is no application code and no automated test suite.
